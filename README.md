# liveLLM

Single-file Snake Deluxe game.

## Controls

- Move with arrow keys or WASD.
- Press `R` for rules.
- Press `P` to pause.
- Press `O` to open the shop.
- Press `Enter` to restart.

## Shop

- Each apple gives 3 coins.
- Use coins to buy accessories.
- You can equip one item per slot at the same time.
